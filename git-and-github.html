Git 与 GitHub

Git 与 GitHub

什么是 Git?

Git 是一个分布式版本控制系统，是 2005 年由 Linus Torvalds（Linux 的创始人）创建的。它完全运行在你自己的电脑上，即使没有网络也能正常工作。

Git 的核心能力：

  • 记录历史 —— 每次你 "commit"（提交），Git 都会给当前文件拍一张快照。你可以随时回到任意一次提交。
  • 分支管理 —— 你可以从主干分出一条"平行时空"来实验新功能，互不干扰，改好了再合并回去。
  • 本地优先 —— 绝大多数操作都在本地硬盘上完成，速度极快。网络只在你需要推送或拉取代码时才用到。

简单来说，Git 是你电脑上的时光机。

什么是 GitHub?

GitHub 是一个基于 Git 的代码托管与协作平台，2018 年被微软收购。它本质上是"运行在云端的 Git 仓库"，但在 Git 的基础上增加了大量功能：

  • 远程仓库 —— 把你的 Git 仓库存在服务器上，方便备份和分享。
  • Pull Request（PR） —— 一种代码审查机制。你改完代码后可以"请求合并"，团队成员可以在合并前逐行审查、评论。
  • Actions（CI/CD） —— 自动化构建、测试和部署流水线。

简单来说，GitHub 是围绕 Git 搭建的社交网络和协作中心。
